# ILoveMyOfficeWorks

My Office Works is an all-in-one file conversion and editing tool built with React. It handles PDFs, images, documents, audio, and video — all from a single, clean interface. Drop a file, pick what you want to do with it, and download the result.

Browser-side operations like PDF merging, splitting, rotating, and image format conversion run instantly using libraries like pdf-lib and the browser canvas API, so files never leave your machine.

Heavier tasks — video and audio conversion via FFmpeg, Office document conversion via LibreOffice, OCR via Tesseract, and PDF compression via Ghostscript — are handled by a lightweight local backend.

The goal is simple: one app for every file conversion and editing task I actually need, without the bloat, accounts, or cloud uploads of commercial tools.
